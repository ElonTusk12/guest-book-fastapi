# Гостевая книга на FastAPI и SQLAlchemy

Самостоятельный JSON API гостевой книги на FastAPI и SQLAlchemy 2.0. Позволяет добавлять отзывы, получать список всех отзывов с возможностью фильтрации по автору, просматривать конкретный отзыв по ID и удалять отзывы. Данные сохраняются в SQLite с помощью асинхронного ORM SQLAlchemy (`AsyncSession`).

## Как запустить

Нужен Python 3.11 или новее. Откройте терминал в папке проекта `guest-book-fastapi`, рядом с `main.py`.

**macOS и Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m alembic upgrade head
python -m uvicorn main:app --reload
```

**Windows (PowerShell)**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

> **Важно:** Перед первым запуском приложения обязательно выполните команду `python -m alembic upgrade head` (или `alembic upgrade head`), чтобы создать таблицу отзывов `review` в базе данных `reviews.sqlite3`.

Откройте [Swagger UI](http://127.0.0.1:8000/docs) в браузере для интерактивного тестирования API. Спецификация OpenAPI доступна по адресу [openapi.json](http://127.0.0.1:8000/openapi.json).

## Маршруты

| Запрос | Назначение | Успешный ответ | Ошибки |
| --- | --- | --- | --- |
| `GET /reviews` | Список отзывов (новые сверху) | `200`, массив отзывов | |
| `GET /reviews?author=Иван` | Фильтрация отзывов по имени автора | `200`, массив отзывов | |
| `GET /reviews/{review_id}` | Получение одного отзыва по ID | `200`, отзыв | `404` (не найден), `422` (невалидный ID) |
| `POST /reviews` | Создание отзыва | `201`, созданный отзыв | `422` (невалидные данные) |
| `DELETE /reviews/{review_id}` | Удаление отзыва по ID | `204`, пустой ответ | `404` (не найден), `422` (невалидный ID) |

### Валидация входных данных

- Поля `author` и `text` обязательны.
- Ограничения длины заданы через Pydantic `Field`:
  - `author`: от 1 до 100 символов.
  - `text`: от 1 до 1000 символов.
- Пробелы по краям строк автоматически очищаются (`strip`).
- Строки, состоящие только из пробелов, отклоняются с кодом `422`.

## Первые запросы в Swagger UI

1. Откройте `http://127.0.0.1:8000/docs`.
2. Раскройте `POST /reviews`, нажмите **Try it out**, укажите тело:
   ```json
   {
     "author": "Иван",
     "text": "Отличный сервис, спасибо!"
   }
   ```
   Нажмите **Execute** и проверьте статус `201` и полученный `id`.
3. Выполните `GET /reviews` — в ответе будет список отзывов.
4. Выполните `GET /reviews/{review_id}` с полученным ID — проверьте статус `200`.
5. Попробуйте передать строку из пробелов в `POST /reviews` — убедитесь в получении ошибки `422`.
6. Выполните `DELETE /reviews/{review_id}` — получите статус `204`. Повторный DELETE вернет `404`.
7. Перезапустите сервер Uvicorn и убедитесь, что сохранённые данные не теряются.

## Тесты

Для запуска тестов установите зависимости для разработки и запустите `pytest`:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

Тесты запускаются в изолированной временной базе SQLite с применением миграций Alembic и проверяют:
- Создание отзыва и получение списка.
- Очистку пробелов и отклонение пустых строк / строк из одних пробелов.
- Валидацию ограничений длины полей `author` и `text`.
- Получение конкретного отзыва и статус `404`.
- Фильтрацию по имени автора.
- Удаление отзыва со статусами `204` и `404` при повторном обращении.
- Сохранение данных в SQLite при перезапуске приложения.
- Корректность OpenAPI-схемы.
- Применение и откат миграций Alembic.
